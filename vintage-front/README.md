# vintage-front

Vintage Mongolia зах зээлийн front-end. Next.js 16 (App Router) + TypeScript + Tailwind CSS 4.
Монгол хэл үндсэн, англи хэл сонголтоор (МН / EN товч, cookie `vm_lang`). Үнэ ₮.

## Ажиллуулах

```
npm install
cp .env.example .env.local   # backend байхгүй бол NEXT_PUBLIC_API_URL-ийг хоосон үлдээнэ
npm run dev                  # http://localhost:3000
```

Шалгах: `npm run lint`, `npm run build`.

## Хуудсууд

| Зам | Агуулга |
| --- | --- |
| `/` | Нүүр: hero, ангилал, шинэ ирсэн (таб), цуглуулга, онцлох дэлгүүр |
| `/products` | Бараа + шүүлтүүр (ангилал, A–D төлөв, он үе, үнэ, хайлт, эрэмбэ). Шүүлтүүр URL-д хадгалагдана: `?category=home,antiques&grade=A&era=70&min=&max=&q=&sort=low` |
| `/products?saved=1` | Хадгалсан (зүрхэлсэн) бараа |
| `/products/[slug]` | Барааны дэлгэрэнгүй: зураг, төлөв, хэмжээ, худалдагч, сагсанд нэмэх |
| `/shops`, `/shops/[slug]` | Дэлгүүрүүд, худалдагчийн дэлгүүр (бараа, үнэлгээ, тухай) |
| `/cart` | Сагс → хүргэлт → төлбөр (QPay / бэлнээр) → баталгаа. Худалдагчаар бүлэглэнэ |
| `/seller` … | Худалдагчийн самбар: тойм, захиалга, миний бараа, шинэ бараа (10% шимтгэлийн тооцоо) |
| `/help` | Хүргэлт, буцаалт, төлбөр, шимтгэл, төлвийн зэрэглэл |

## Бүтэц

```
src/
├── app/
│   ├── (store)/      Толгой, хөлтэй дэлгүүрийн хуудсууд
│   ├── (checkout)/   Энгийн толгойтой сагс/төлбөр
│   └── seller/       Худалдагчийн самбар
├── components/       UI хэсгүүд (seller/ дэд хавтас)
└── lib/
    ├── api.ts        Backend дуудлага + жишээ өгөгдөл рүү буцах
    ├── mock-data.ts  Жишээ бараа, худалдагч, захиалга
    ├── i18n.ts       МН / EN текст

```

## Backend-тэй холбох

`.env.local`-д `NEXT_PUBLIC_API_URL=http://localhost:5000/v1` тохируулбал бүх хуудас vintage-back-аас уншина.
Хоосон бол жишээ өгөгдлөөр (`lib/mock-data.ts`) ажиллана.

- Бараа, дэлгүүр: `/product` (шүүлтүүр backend талд), `/shop`.
- Захиалга: `POST /order`, хүргэлтийн хэлбэртэй.
- `/login`, `/register`: утас + нууц үг. Token нь httpOnly `vm_token` cookie-д хадгалагдана (`lib/actions.ts`).
- `/seller`: нэвтрээгүй бол `/login` руу, дэлгүүргүй бол "Дэлгүүр нээх" форм. Тойм, захиалга, бараа нь
  `/seller/*`-аас, "Илгээсэн" товч болон шинэ бараа (зурагтай) server action-аар хадгалагдана.
- `API_SERVER_URL`: Next server-ээс backend руу дуудах дотоод хаяг (Docker-т `http://back:5000/v1`).
- Худалдагч бараагаа засах (`/seller/products/[id]`), устгах боломжтой (зарагдсаныг устгахгүй).
- `/account`: нэвтэрсэн худалдан авагчийн захиалгууд. Захиалга server action-аар (token-той) илгээгдэх тул бүртгэлд холбогдоно.
- `/track`: захиалгын дугаар + утсаар шалгах (нэвтрээгүй ч болно).
- `/admin`: зөвхөн `admin` эрхтэй. Бүх захиалга (төлөв солих), дэлгүүр (нээх/түр хаах/хаах), хэрэглэгч (хаах).
- Худалдагчийн сэтгэгдэл, QPay QR одоогоор жишээ.
